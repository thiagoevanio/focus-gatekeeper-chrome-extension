# Demo Video Script

1. Open `chrome://extensions`.
2. Load the unpacked extension.
3. Open the onboarding page and click `Set up my sites`.
4. Add or edit `youtube.com`.
5. Set focus limit to `1` minute and break to `1` minute.
6. Switch between light and dark theme.
7. Save changes.
8. Open YouTube and keep the tab active.
9. Show the warning before the blocking state starts.
10. Show the overlay when the limit is reached.
11. Wait for the countdown to finish and show the page unlocking.
12. Open the popup and show the updated progress/stats.

Suggested length: 45 to 75 seconds.
