# Privacy Policy

Focus Gatekeeper is a local-first browser extension.

## Data Stored Locally

The extension stores the following data in Chrome local storage:

- User-defined tracked domains
- Focus limits and pause settings
- Language preference
- Daily and weekly usage totals
- Recent pause history

## Data Collection

Focus Gatekeeper does not collect, sell, transmit, or share personal data.

The extension does not use analytics, advertising identifiers, third-party trackers, or a remote backend.

## Website Access

The extension requests access to web pages so it can:

- Detect whether the current page matches a user-defined tracked domain
- Count active time only when the tab is visible and the Chrome window is focused
- Display the blocking overlay when a focus limit is reached

## User Control

Users can reset usage data, remove tracked sites, disable tracking, or export/import settings from the options page.
