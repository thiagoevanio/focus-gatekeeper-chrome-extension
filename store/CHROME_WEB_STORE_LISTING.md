# Chrome Web Store Listing

## Name

Focus Gatekeeper

## Short Description

Track distracting sites and enforce intentional pause timers when your focus limit is reached.

## Detailed Description

Focus Gatekeeper helps you keep distracting websites under control without sending your browsing data anywhere.

Choose the sites that drain your attention, set a focus limit, and keep browsing normally. When the limit is reached, Focus Gatekeeper covers the page with a full-screen animated pause overlay. The page unlocks automatically when the break timer expires.

Features:

- Active-tab and focused-window time tracking
- Per-site focus limits
- Pause modes: site timer, short break, long break, and block until tomorrow
- Optional work-hours schedule
- Gentle pre-block warning before a pause starts
- Light and dark themes
- Weekly stats and total time saved
- Quick popup dashboard
- Full options page
- English and Portuguese (Brazil)
- Local-first storage
- No analytics, no ads, no remote backend
