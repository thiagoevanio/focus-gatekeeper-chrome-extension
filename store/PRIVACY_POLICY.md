# Privacy Policy

Focus Gatekeeper stores settings and usage data locally in the user's browser using `chrome.storage.local`.

The extension does not collect, transmit, sell, or share personal data. There is no analytics system, advertising tracker, third-party SDK, or remote backend in this version.

The extension reads the current page URL only to determine whether it matches a user-defined tracked domain. Usage totals, pause sessions, tracked domains, and preferences remain on the user's device unless the user manually exports the settings file.

Users can remove tracked sites, reset usage data, disable tracking, export settings, or import settings at any time from the options page.
